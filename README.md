# Abishek's Memories

A self-hosted, cinematic personal memory archive. The project includes a responsive public museum, server-side private archive, admin CMS, file uploads, albums, love-story chapters, comments, likes, downloads, and editable site settings.

## Run locally

1. Install Node.js 18+.
2. Run `npm install`.
3. Copy `.env.example` to `.env` and set unique secrets. Never commit `.env`.
4. Run `npm start`.
5. Visit `http://localhost:3000` and `http://localhost:3000/admin.html`.

The server creates `data/content.json` and `uploads/` on first run. Both are intentionally ignored by Git and should be backed up securely. For production, use HTTPS, a strong `SESSION_SECRET`, a persistent disk/private object storage, and set `COOKIE_SECURE=true`.

## Security model

Uploaded files are never served from a public static directory. Every media request passes through a server route that checks public visibility or the private archive session. Admin routes require an authenticated session. Cookies are HttpOnly, SameSite=Lax, and rate limits protect login and public interactions. User text is escaped before rendering in the browser.

Use `ADMIN_PASSWORD_HASH` with a scrypt hash generated by your deployment tooling when possible; the plain `ADMIN_PASSWORD` fallback exists for simple local setup only.

## Content workflow

Sign in to the admin panel to upload media, write memories, create albums, add love-story chapters, manage visibility, moderate comments, and edit the about/contact/social settings. Empty states are intentional: add only real memories and personal details.
